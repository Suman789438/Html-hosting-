Startup Command

সার্ভার Run করলে ঠিক কোন কমান্ডটি এক্সিকিউট হবে তা এখানে নির্ধারণ করুন। ইচ্ছেমতো এডিট করতে পারবেন।

python3 main.py python3 bot.py node index.js install + run
ডিফল্টভাবে Run বাটনে ক্লিক করলে Files ট্যাব থেকে বাছাই করা মেইন ফাইলটি চলবে। এখানে কাস্টম স্টার্টআপ কমান্ড সেট করলে সেটিই ব্যবহার হবে।
requirements.txt — Dependency Installer

আপনার বট বা অ্যাপের জন্য প্রয়োজনীয় প্যাকেজগুলো এখানে লিখুন (এক লাইনে একটি করে), তারপর Install চাপুন।

Install চাপলে Live Console-এ গিয়ে pip install -r requirements.txt এর মতো রিয়েল-টাইম প্রসেস লগ দেখতে পাবেন।
